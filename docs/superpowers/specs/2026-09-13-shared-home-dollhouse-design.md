# 合租屋俯视户型首页改造设计

**状态：已确认，待实现**  
**范围：现有 Node.js 原型的视觉与首页交互改造，不改变 MVP 功能边界。**

## 目标

将首页由传统待办卡片首页改为“白色微缩合租屋”的正俯视户型模型。它既展示六人合租屋的空间关系，也作为费用、值日、补货与公约的可视化入口。

## 视觉规则

- 使用正俯视、紧裁切的六卧室户型图；画面外不保留投影或悬浮感。
- 左右各三间相邻卧室，中央为贯通走廊；六间卧室面积和基础家具规模一致。
- 顶部为餐厨区，中部走廊入口为管理角，底部为客厅与活动区。
- 基调为白墙、浅木地板、低饱和鼠尾草绿/蜜桃色/暖金色；任务色只用于状态提示。
- 三位已入住成员以圆形真实头像出现在其房间；空房不显示头像。
- 所有图形和角色均为原创，不使用参考图中的办公室、角色或品牌素材。

## 首页结构

1. 顶部：屋名、当月结算进度、通知入口。
2. 主场景：户型图占首屏约 55% 的可视区域。
3. 待办摘要：位于户型图下方，横向展示“待付款、今日值日、待补货、待确认公约”。
4. 底部：保留首页、费用、生活、我的四项导航。

## 空间与功能映射

| 空间热点 | 对应功能 | 状态表达 | 点击结果 |
|---|---|---|---|
| 成员卧室与头像 | 该成员待办、费用状态 | 头像边框或小状态点 | 打开该成员相关的待办摘要 |
| 顶部餐厨区 | 公共采购、物品库存 | 纸巾/清洁用品的低库存提示 | 打开物品与补货流程 |
| 中部管理角 | 费用、值日、公约 | 电表、账单夹、公告板、清洁车的小提示 | 打开对应待处理项目 |
| 底部客厅活动区 | 本周生活安排、公共任务 | 一枚活动/任务提示 | 打开生活页 |

## 状态与交互

- 延用已有 `localStorage` 数据结构和费用、值日、补货、公约动作。
- 操作完成后，首页待办数、户型热点提示、成员头像状态同步更新。
- 户型图仅承担快捷入口和状态概览；所有关键动作仍提供清晰文字按钮，避免用户必须猜测点击位置。
- 在窄屏上，户型图允许纵向完整展示，不横向裁切；热点点击目标最小为 44px。

## 验收标准

1. 首页在手机宽度下完整展示户型图和底部待办摘要，无横向滚动。
2. 六间卧室视觉面积一致；三位入住成员显示头像，空房不显示头像。
3. 费用、值日、补货、公约的待办均能在对应空间显示可辨识状态，并可进入相应操作。
4. 完成值日、标记转账、认领/完成补货、确认公约后，户型热点和待办摘要立即更新且刷新后仍保留。
5. 原有费用 AA、补货转账单、值日完成/换班和公约确认流程保持可用。

## 非目标

- 不新增真实支付、后端、成员匹配或室友评分。
- 不将户型图做成可自由拖拽、缩放或装修的游戏化系统。
