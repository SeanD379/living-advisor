# 合租生活管家蓝白产品视觉改版设计

## 目标与范围

本轮仅重做现有移动端原型的布局与视觉语言，不增加新的业务模块、不调整费用、值日、物品、公约的本地数据逻辑。四个一级页面（首页、费用、生活、我的）统一为现代蓝白的移动应用体验；首页继续以现有的正俯视合租屋模型为唯一主体内容，模型不裁切、不替换为数据仪表盘。

## 视觉原则

- 用冷灰背景、白色表面和深灰文字建立清晰的 Apple 式信息层级。
- 使用干净的系统蓝作为唯一主色，用于主按钮、当前导航、链接、选中状态和焦点状态。
- 费用、家务、物品、公约只在状态标签、图标底和小范围摘要中使用橙、绿、黄、紫等语义色；每一种颜色都配合文字说明，不能只靠颜色传达状态。
- 不使用马卡龙大面积底色、深色霓虹/蓝紫渐变、彩虹渐变或厚重投影。摘要卡允许白到同色系极浅色的低对比过渡，但不作为装饰性大色块。
- 所有卡片、控件和弹层使用统一大圆角、细分隔线和轻微层级阴影；保留充足留白但不牺牲信息密度。

## 页面布局

### 全局壳层与导航

手机宽度优先；大屏仍以居中的手机原型展示。顶部使用简洁房屋标题，移除非必要标语和头像。底部导航保持首页、费用、生活、我的四项，但改为浮于内容之上的白色圆角胶囊：当前项以浅蓝选中底板、蓝色图标和文字呈现，未选中项为中性灰。

页面底部为固定导航预留安全空间；首页例外，模型内容结束后直接衔接导航，不能出现额外空白。

### 首页：空间状态模型

现有户型图保持原始的暖木色、家具细节、六间卧室和三位室友头像。它是首页主视觉，完整显示，并保留四个无障碍热点。

模型图片内部原有的白色留边必须与页面冷灰背景（`#F5F7FA`）融为一体。模型使用完整显示模式，不得裁切底部活动区；模型的可视底边直接衔接悬浮导航胶囊上沿，不得在两者之间保留空白带。

三位已入住室友的头像作为独立可点击入口，放在各自房间的几何中心；空房间不添加头像。点击头像只展示昵称、房间、当前合租状态和待处理事项摘要，不展示手机号、真实住址、支付账户等隐私信息。空间热点仍负责区域状态入口。首页顶部房屋名称改为居中标题，下拉箭头与标题保持同一居中组。

热点改为更精致的状态标记：白色外环、按事项使用语义色的中心点，已解决事项不显示标记。点击后沿用既有模态信息与跳转：房间为个人状态、餐厨区为物品、管理角为待处理、活动区进入生活。页面不重新加入模型下方的待办卡片或快捷宫格。

### 费用

页头保留“费用 AA”与新增入口。摘要改为一个白色、蓝色重点数字的双列结算卡，待支付金额带橙色状态提示。账单使用分组列表卡：左侧语义图标、中间账单信息、右侧金额；底部展示已结清进度和“我应付/我已转账”文字标签。新增账单入口使用蓝色圆形按钮，详情和确认操作使用蓝色主按钮。

### 生活

“值日 / 物品 / 公约”维持现有结构，但改为清晰的分段控件和分组表面。值日任务采用日期标识、任务、负责人和操作按钮的单行卡片；物品显示库存值和带文字的状态胶囊；公约采用紫色小标签标识待确认及确认进度。完成、认领和换班等操作的状态反馈仍由现有 Toast 呈现，改用蓝白容器与对应语义图标。

### 我的

个人信息使用白色资料卡，头像为蓝色圆形占位；房屋、结算日等信息在同一卡片中有清晰主次关系。设置项组成一个带细分隔线的圆角列表，右侧使用统一线性箭头。重置演示数据与普通设置项分离，使用风险红色文字按钮，避免误触。

### 弹层与反馈

所有现有底部弹层统一为白色圆角 sheet，使用半透明冷灰遮罩、蓝色主操作按钮和明显关闭按钮。保留 Escape 关闭、触发点焦点恢复、键盘可达性。输入框、下拉选择器、筛选器使用白底、浅灰描边和蓝色 focus ring；错误和成功提示分别有文本与语义图标。

## 实现边界与验证

- 只调整 `public/index.html`、`public/style.css`、`public/app.js` 内的表现层，保留 `home-state.js` 的状态派生逻辑和测试。
- 不引入第三方 UI 库、远程图片或后端接口；图标以现有文本符号为临时实现，若替换，统一为内联 SVG 线性图标。
- 保持 localStorage 数据、弹层交互、费用结算、值日完成、物品认领/补货、公约确认和模型热点行为不变。
- 验收：375px 及当前桌面手机框均无横向滚动；模型完整显示且直接接到导航；四页蓝白层级统一；语义色不覆盖整页且无深色或多彩渐变；键盘焦点、弹层关闭和减少动态效果继续可用；既有状态单元测试全部通过。
